# Java Invoice Generator

## Description
A console-based Java application that generates a formatted invoice based on user input. Calculates subtotal, tax, and total.

## Features
- Object-Oriented structure
- Input validation
- Customizable invoice output
- Easy to run

## Technologies Used
- Java
- Eclipse

## How to Run
1. Clone this repo
2. Open in Eclipse or your IDE
3. Run `InvoiceGenerator.java`
